# MotionForge · Logo et charte

Logo retenu : **« Play forgé »** (bouton lecture + traits de vitesse + étincelle de forge).
Aperçu de tout le kit : `charte.html` (ou `charte.png`).

## Couleurs

| Nom | Code | Usage |
|---|---|---|
| Noir forge | `#0E0E12` | fonds sombres, texte sur fond clair |
| Orange forge | `#FF6A1A` | couleur de marque, boutons d'achat, « Forge » |
| Crème | `#F6F1E7` | fonds clairs, texte sur fond sombre |
| Étincelle | `#E8B04B` | accent rare (l'étincelle, un détail), jamais pour du texte |

## Polices

- **Unbounded Black** : titres et logo
- **Inter** : textes courants

Les deux sont sous licence libre (SIL OFL) et déjà incluses dans l'application MotionForge.
Dans les fichiers du logo, le texte est converti en tracés : il s'affiche à l'identique sans la police.

## Quel fichier pour quel usage

| Usage | Fichier |
|---|---|
| Photo de profil (Facebook, Instagram, TikTok, WhatsApp Business, YouTube) | `png/motionforge-profil-1080.png` (prévu pour un recadrage rond) |
| Icône de l'application, raccourci du Bureau | `png/motionforge-icone-512.png` · `logo/motionforge-icone.svg` |
| Favicon du site | `logo/favicon.svg` + `png/favicon.ico` + `png/apple-touch-icon.png` |
| En-tête du site, page de vente sur fond sombre | `logo/motionforge-horizontal-sombre-transparent.svg` |
| En-tête du site sur fond clair | `logo/motionforge-horizontal-clair-transparent.svg` |
| Petit espace (menu, pied de page) | `logo/motionforge-horizontal-court-*.svg` (sans la phrase) |
| Carte de fin des vidéos, visuels pub | `png/motionforge-horizontal-sombre.png` / `-clair.png` |
| Filigrane sur les vidéos et photos | `png/motionforge-mono-blanc.png` ou `png/motionforge-symbole-mono-blanc-512.png` |
| Impression une couleur, tampon | `logo/motionforge-mono-noir.svg` |
| Symbole seul (sticker, coin d'une vidéo) | `logo/motionforge-symbole.svg` (fond sombre) · `-sur-clair.svg` (fond clair) |

Les SVG s'agrandissent sans perte : à préférer partout où c'est possible (site, impression).
Les PNG du logo horizontal font 3 012 px de large.

## Règles

- Laisse autour du logo un espace vide au moins égal à la hauteur du triangle.
- Taille minimale : 120 px de large pour le logo horizontal, 32 px pour le symbole
  (en dessous, utilise le favicon simplifié, sans traits de vitesse).
- Ne pas déformer, pivoter, changer les couleurs, ajouter d'ombre ni de contour.
- Sur une photo chargée : version monochrome blanche, ou logo sur son fond sombre.

Les anciennes propositions (B · L'enclume, C · Monogramme MF) sont gardées dans `propositions/`.
